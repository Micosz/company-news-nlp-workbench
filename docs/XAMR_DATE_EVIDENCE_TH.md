# ทดลองใช้หลักฐานวันที่ก่อนระงับการรวมกลุ่ม

รันวันที่ 15 พฤศจิกายน 2026 (เวลาไทย) บน ECB+ Ann1 dev และ Ann2 dev ของผู้เขียน X-AMR ชุดละ 1,245 mentions ใช้กราฟ OR กราฟเดียวกันภายในแต่ละชุด เรียงเส้นเชื่อมแบบเดิม ตั้ง tolerance 0 วัน และใช้ gold cluster เฉพาะตอนประเมิน ไม่มีการทดลองชุด test_common หรือรวมชุดข่าวเพิ่มเติมในครั้งนี้

## วิธีที่ทดลอง

เพิ่มโหมด CLI `date_evidence` เพื่อรัน OR, OR + Temporal เดิม และ OR + Date Evidence ในคำสั่งเดียว วิธีใหม่แยกหลักฐานดังนี้

- **event** ใช้ `argT` เป็นเงื่อนไขระงับการรวมเมื่อเป็นวันระดับวัน และประโยคของ mention มีวันที่เต็มเพียงค่าเดียวที่ตรงกัน รวมถึงตรวจว่าประโยคไม่ขึ้นต้นด้วยคำบอกวันเผยแพร่
- **publication** วันที่จาก `argT` ตรงกับวันในหัวเอกสารที่เข้ากฎตรวจหัวข่าวหรือเวลาเผยแพร่/อัปเดต เก็บเป็นตัวเลือกจากหัวข่าวและเว้นจากการระงับการรวม
- **unknown** วันว่าง อ่านไม่ได้ เป็นช่วง หรือหลักฐานระดับประโยคยังไม่พอ เว้นจากการระงับการรวมโดยไม่เดาวันใหม่

วิธีนี้ตรวจหลักฐานรองรับ `argT` เฉพาะสำหรับกฎระงับการรวม กราฟ OR ยังสร้างจากอินพุตชุดเดิม ซึ่งรวม `argT` ใน EID_lt ไม่มีการแก้คำกำกับต้นฉบับหรือใช้ผลของ Ann1 แทน Ann2 คำว่า event และ publication เป็นป้ายจากกฎ ข้อความวันเดียวในประโยคอาจอ้างเหตุการณ์อื่น และวันที่แบบตัวเลขในหัวข่าวอาจมีสองการตีความ กฎยังไม่อ่านวันสัมพัทธ์หรือเชื่อมหลักฐานข้ามประโยค

วิธีใหม่ให้ผลจัดกลุ่มตรงกับ OR ทุก mention ในทั้งสองชุด เทียบกับ Temporal เดิม Ann1 กู้คืนคู่ที่เคยแยกผิด 30 คู่และกลับมารวมผิด 433 คู่ ส่วน Ann2 กู้คืนคู่ที่เคยแยกผิด 674 คู่และกลับมารวมผิด 446 คู่ การทดลองนี้แสดงว่ากฎคัดหลักฐานเข้มจนเหลือวันไม่พอให้เงื่อนไขเวลามีผล จึงยังไม่มีผลสนับสนุนให้ใช้วิธีนี้แทน baseline

- Ann2 คู่ `35_10ecbplus.xml_82` และ `35_1ecbplus.xml_105` ในข่าว Jamal Williams มี `argT` ตรงกับตัวเลือกวันที่หัวข่าว 4 และ 3 ก.พ. 2009 ส่วนข้อความเรื่องเหตุใช้วันอาทิตย์เป็นจุดอ้างอิง กฎใหม่จึงจัดสองวันเป็น publication และไม่ได้อนุมานวันอาทิตย์เป็นวันเกิดเหตุ กรณีนี้ใช้ชี้ว่าที่มาของวันมีผล แต่ยังอธิบายคู่ที่แยกผิดทั้งหมดไม่ได้
- Ann1 คู่ `12_5ecbplus.xml_10` กับ `12_19ecb.xml_27` กล่าวถึงเรือ INS Sukanya กับ INS Mysore ซึ่งอยู่คนละกลุ่มอ้างอิง Temporal เดิมแยกได้ แต่วิธีใหม่กลับมารวมผิด

## รันซ้ำและตรวจหลักฐาน

```sh
.venv-xamr/bin/python xamr_lab/cli.py --dataset ann1-dev --method-selection date_evidence --tolerance-days 0
.venv-xamr/bin/python xamr_lab/cli.py --dataset ann2-dev --method-selection date_evidence --tolerance-days 0
.venv-xamr/bin/python xamr_lab/cli.py --replay xamr_lab/runs/20261115T065802-09a3ec26
```
