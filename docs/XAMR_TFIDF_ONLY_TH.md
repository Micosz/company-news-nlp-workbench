# ทดลองใช้ TF-IDF โดยตรงกับ X-AMR

## โปรโตคอลที่ตรึงก่อนรัน

ใช้ Ann1/Ann2 ตาม split ต้นฉบับ แยก fit ต่อ annotator สร้างผู้สมัครจากทุกคู่คนละเอกสารในหัวข้อเดียวกัน มีทุก mention เป็นโหนดแม้ไม่มีเส้น ฝึก TF-IDF word 1–2 grams, lowercase, L2, min_df 1, max_features 30,000 จากประโยคของ mention ในคู่ฝึก โดยนับข้อความซ้ำเพียงครั้งเดียว คำนวณ cosine โดยตรง ไม่มีการแบ่ง bin และไม่มี Naive Bayes ในการให้คะแนน การตัดเส้น หรือการเลือกวิธี

- **TF-IDF อย่างเดียว:** สร้างเส้นเมื่อ cosine ≥ threshold เลือกจาก **0.15, 0.30, 0.50, 0.70** แล้วจัดกลุ่มด้วย connected components
- **ช่วย OR ตัดเส้น:** เฉพาะเส้นคนละเอกสารที่มาจาก EID_lt อย่างเดียว ตัดเมื่อ cosine ต่ำกว่า **0.05 หรือ 0.10** เส้น EID_N และเส้นในเอกสารยังอยู่
- **ช่วย OR เติมเส้น:** เฉพาะคู่ที่ยังอยู่คนละกลุ่ม OR และไม่มีเส้นเดิม ต้องมี roleset เดียวกัน และมี ARG0 หรือ ARG1 ที่ไม่ว่างและตรงกันใน slot เดียวกันหลัง normalize ข้อความ ARG ที่เป็น roleset ซ้อนจะไม่ใช้เป็นหลักฐานชื่อ ใช้ cosine ≥ **0.50 หรือ 0.70** เลือกคู่กลุ่มที่แต่ละกลุ่มให้คะแนนสูงสุดแก่กันทั้งสองฝั่ง และต้องไม่มีคู่คะแนนสูงสุดเสมอกัน คืนเพียงหนึ่งรอบ เพื่อจำกัดการรวมลูกโซ่
- **OR คงเดิม** เป็นตัวเลือกที่ห้าของ hybrid ไม่มีการซ้อนกฎเติมกับกฎตัดในรอบนี้ ค่า threshold เป็นกริดที่ตั้งไว้ก่อนรัน ผลแต่ละ fold ใช้ TF-IDF ที่ fit จากหัวข้อฝึกของ fold นั้นเท่านั้น
- ใช้ 5-fold GroupKFold ตาม topic ใน train และเลือกจากค่าเฉลี่ย CoNLL F1 บนกลุ่ม validation สำหรับ standalone หากเสมอเลือก threshold สูงกว่า สำหรับ hybrid หากเสมอเลือก OR ก่อนและเรียง `cut_0.05`, `cut_0.10`, `add_0.70`, `add_0.50` ตามลำดับ Freeze สองวิธีที่ชนะก่อนโหลด dev ใช้ dev เฉพาะวิธีที่เลือก ไม่เปิด test_common ไม่ปรับกริดตามผล dev
- วัด gold แบบ `(topic, gold_cluster)` สำหรับทุกวิธี โดยไม่แก้ไฟล์ต้นฉบับ Gold ใช้เฉพาะ scorer ส่วน topic และ doc ใช้สร้างคู่/กราฟเท่านั้น กฎเสริม OR ใช้ input roleset, argument และกราฟจากคำกำกับ X-AMR ของผู้เขียน ไม่แก้คำกำกับ เทียบทั้ง OR เดิมและ OR ที่จำกัดคู่ข้ามเอกสาร ฐานของ hybrid หลักคือ OR เดิม และรายงานผลด้วยฐาน OR ข้ามเอกสารเพิ่มเมื่อใช้กฎที่เลือก รายงาน CoNLL, Pair P/R/F1, FP/FN, ผลรายหัวข้อและเส้นที่เปลี่ยน

## ทำซ้ำและตรวจหลักฐาน

ใช้ Python environment ของ Pair Workbench และ pure Python modules ตาม [ขั้นตอน TF-IDF NB](XAMR_TFIDF_NB_TH.md#รันซ้ำและหลักฐานในเครื่อง) การรันขั้นนี้เรียก TF-IDF กับ cosine เท่านั้น ตัวช่วยคู่และกราฟ import จากโมดูลเดิมโดยไม่เรียกฝึกหรือทำนาย NB

```sh
PYTHONPATH="$xamr_text_deps" pair_workbench/.venv/bin/python xamr_lab/tfidf_only.py --annotator ann1
PYTHONPATH="$xamr_text_deps" pair_workbench/.venv/bin/python xamr_lab/tfidf_only.py --annotator ann2
(cd xamr_lab && PYTHONPATH="$xamr_text_deps" ../pair_workbench/.venv/bin/python -m unittest -q test_tfidf_nb test_or_nb_hybrid test_tfidf_only)
```

ผลอยู่ใน `xamr_lab/runs/tfidf-only/` รอบ Ann1 `20261115T163953-df5656b6` และ Ann2 `20261115T163953-c0037931` มี config ที่ freeze, data/source hashes, metrics, topic scores, predictions และรายการเส้น/คู่ที่เปลี่ยน ตรวจกับ OR จากรอบเดิมตรงทั้งกราฟเต็มและข้ามเอกสาร ตรวจ 25 หัวข้อใน 5 folds ไม่รั่ว และเล่นซ้ำได้ CSV/config ตรงกัน ผ่าน 35 tests เวลา CV+fit ประมาณ 2.21–2.23 วินาที และ dev inference 0.13–0.15 วินาทีต่อชุด ไม่รวม scorer
