# ชุด Pilot บทบาทผู้ซื้อ–เป้าหมายที่ AI ช่วยเตรียม

โครงการนี้ทดลองว่า buyer/target ช่วยจับคู่ข้อความเกี่ยวกับเหตุการณ์เดียวกันหรือไม่ ชุดนี้ใช้ ECB+ Pilot เดิม 42 event mentions จาก 42 เอกสาร, 4 เหตุการณ์ และ 424 คู่ ป้าย same-event มาจาก ECB+ เดิม ไม่ได้สร้างจาก buyer/target

AI ช่วยอ่านข่าวฉบับเต็มของแต่ละ mention แล้วเสนอผู้ซื้อ–เป้าหมายและหลักฐาน รวมทั้งปรับชื่อย่อเป็นชื่อมาตรฐาน บางแถวต้องเชื่อมข้อความข้ามประโยค **ยังไม่มีคนตรวจทาน** จึงไม่ใช่ human gold หรือ oracle ผลไม่ได้วัดความแม่นยำของการสกัดบทบาทอัตโนมัติ ตำแหน่งหลักฐานและ SHA-256 ของข่าวต้นฉบับอยู่ใน `data/pilot/pilot_roles_ai_provisional.csv` ไม่มีข่าวฉบับเต็มในไฟล์นี้

## โหลดและทดลองในเว็บ

1. ติดตั้งและเปิดเว็บตาม [README](../README.md#ติดตั้งบนเครื่องใหม่)
2. ในส่วน **01 ข้อมูลทดลอง** เลือก `Pilot A + บทบาทจาก AI` แล้วกด **โหลดข้อมูล** ได้ทันที ไม่ต้องอัปโหลดไฟล์ ระบบจะตั้งที่มาบทบาทเป็น **โมเดลทำนาย** ให้
3. ในส่วน **02 อัลกอริทึม** ตรวจโค้ดและบันทึกหมายเหตุ จากนั้นกด **รันและบันทึกการทดลอง**
4. ดู Text baseline และ Text + roles ในส่วน 03; ส่วน 04 เก็บรอบทดลองในเครื่อง พร้อมไฟล์สำหรับดาวน์โหลด
5. เลือก `Pilot B + บทบาทจาก AI` เพื่อสลับทิศ หรือเลือก Pilot ที่ไม่มีบทบาทเพื่อทดลองแบบเดิม

| ชุด | Train | Test | คู่ทั้งหมด |
| --- | --- | --- | --- |
| A | AMD 253 คู่ | HP 171 คู่ | 424 |
| B | HP 171 คู่ | AMD 253 คู่ | 424 |

บทบาทครบ 424/424 คู่ หมายถึง **ความครอบคลุม ไม่ใช่ความถูกต้อง** A/B เป็นการสลับข้อมูลเดียวกัน ไม่ใช่ test อิสระสองชุด คู่ 424 คู่ก็มาจาก mentions เดิม ไม่ใช่ 424 เหตุการณ์อิสระ

ในชุดที่โหลดจากเว็บ ข้อความที่ทั้งสองโมเดลเห็นเป็น **ข้อความสั้นเดิม** แต่การเตรียม buyer/target บางรายการอาศัยข่าวเต็มเพิ่มเติม ฟีเจอร์บทบาทจึงอาจมีข้อมูลที่ข้อความสั้นไม่บอก และไม่ใช่การเปรียบเทียบที่ใช้ข้อมูลตั้งต้นเท่ากันทั้งหมด ชุดนี้รองรับ B³ เมื่อคู่ test และ reference ครบ แต่ B³ ไม่ใช่ CoNLL F1 หรือการรัน CohTP

## สร้างชุดข่าวฉบับเต็มและตารางหลักฐานในเครื่อง (ทางเลือก)

หากต้องการให้ทั้ง Text และ Text + roles เห็นข้อความฉบับเต็มเดียวกัน ให้ดาวน์โหลดไฟล์ `ECB+.zip` จาก [แหล่ง ECB+ ของผู้จัดทำ](https://github.com/cltl/ecbPlus/tree/master/ECB%2B_LREC2014) มาไว้ในเครื่อง แล้วสั่งจากโฟลเดอร์ repo:

```sh
# macOS / Linux — เปลี่ยน path ให้ตรงกับไฟล์ที่ดาวน์โหลด
.venv/bin/python scripts/build_full_article_roles.py --source-zip /path/to/ECB+.zip --output-dir local_data/full_article_pilot
```

บน Windows PowerShell ใช้ `.venv\Scripts\python.exe` แทน `.venv/bin/python` และระบุ path ในเครื่องของตน สคริปต์ตรวจ SHA-256 ของ archive, สร้างคู่ Pilot A/B และตารางหลักฐานในโฟลเดอร์ปลายทางโดยไม่เขียนทับไฟล์เดิม แล้วนำไฟล์คู่ `.csv` เข้าเว็บผ่าน **นำเข้า Excel / CSV** โดยเลือกที่มาบทบาทเป็น **โมเดลทำนาย** ไม่ใช่คนทำป้ายกำกับ

ชุดข่าวเต็มวัดผลระดับคู่ได้ แต่ B³ ของเว็บปัจจุบันจะข้ามเพราะข้อความไม่ตรงกับ Pilot reference แบบสั้น ข่าวฉบับเต็มและผลรันไม่ได้อยู่ใน Git; สิทธิ annotation ของ ECB+ กับสิทธิข้อความข่าวอาจแยกกัน ดู [ข้อมูลและแหล่งที่มา](DATA_SOURCES_TH.md)

## ตีความอย่างระมัดระวัง

Pilot มีเพียง 4 focal events และแต่ละดีลมีหนึ่ง focal event ทำให้ชื่อบริษัทเป้าหมายอาจเป็นทางลัดในการเดากลุ่ม ผลสำรวจ Text + roles ที่ได้ F1 100% จึงไม่ได้พิสูจน์ว่าระบบแม่นยำทั่วไป หรือแยกเหตุการณ์ต่างช่วงของดีลเดียวกันได้ ควรให้คนตรวจบทบาทกับข่าว และเตรียม held-out ใหม่ที่มีหลายเหตุการณ์ต่อดีลก่อนสรุปผล

อ้างอิง ECB+: Agata Cybulska and Piek Vossen (2014), [Using a sledgehammer to crack a nut? Lexical diversity and event coreference resolution](https://aclanthology.org/L14-1646/). บทบาท buyer/target ชุดนี้เป็นส่วนเพิ่มเติมโดย AI ไม่ใช่ annotation ของผู้จัดทำ ECB+.
