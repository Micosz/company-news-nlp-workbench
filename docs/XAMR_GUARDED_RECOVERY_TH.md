# ทดลองประกอบการตรวจ ARG1 กับการคืนเส้นข้ามเวลา

## แผนก่อนรัน

ใช้ Ann1/Ann2 dev ต้นฉบับชุดละ 1,245 mentions ตาราง 2×2 ใช้ Temporal 0 เดิมเป็นช่องปิดทั้งสองกฎ โดยมี OR เป็นตัวอ้างอิงนอกตาราง ตรึง tolerance ที่ 0 วันและใช้ Context Recovery เดิมโดยไม่เปลี่ยนเกณฑ์หรือข้อมูลเข้า

| ARG1 แบบประโยค | คืนเส้น | วิธี |
|---|---|---|
| ปิด | ปิด | Temporal 0 |
| ปิด | เปิด | Context Recovery เดิม |
| เปิด | ปิด | ตัดเส้น ARG1 ก่อน Temporal |
| เปิด | เปิด | ตัดเส้น ARG1 ก่อน Temporal แล้วคืนเส้นแบบคุ้มครองคู่ที่ ARG1 แยก |

ใช้รายการตัดจาก Sentence Alignment เดิมกับกราฟ OR ก่อนสร้างกลุ่ม Temporal การคืนเส้นพิจารณาเฉพาะ temporal veto ในกราฟที่ผ่านการตัด และตรวจเพิ่มว่าการรวมสองกลุ่มจะไม่ทำให้ปลายของเส้น ARG1 ที่ถูกตัดและอยู่คนละกลุ่มกลับมาอยู่ด้วยกันทางอ้อม แล้วจึงใช้เงื่อนไขกลุ่มเสนอคู่เดียวตรงกันเดิม หากปลายเส้นยังอยู่ด้วยกันหลัง Temporal ให้นับไว้เป็นข้อจำกัดของการตัดเส้นระดับกราฟ ไม่อ้างว่า ARG1 เป็นข้อห้ามแบบเด็ดขาดตั้งแต่ต้น

เพิ่มตัววินิจฉัยลำดับสองแบบแบบแยกจาก matrix: (1) ตัด ARG1 ก่อนแต่ให้ขั้นคืนเส้นทำงานโดยไม่กันการคืนทางอ้อม (2) ทำ Temporal และคืนเส้นก่อน แล้วตัด ARG1 บนกราฟ OR ที่จำกัดอยู่ในแต่ละกลุ่มผลลัพธ์ก่อนหา connected components อีกครั้ง กรณีหลังไม่รัน Temporal ซ้ำ ใช้ตรวจผลของการจัดลำดับว่าการตัดเส้นปลายทางเพียงพอหรือเปล่า

[CohTP กรกฎาคม 2026](https://aclanthology.org/2026.acl-long.1345/) สนับสนุนแนวคิดกลับมาตรวจเส้นที่เวลาแยก ส่วน [EAE v1 กรกฎาคม 2026](https://arxiv.org/abs/2607.16808) สนับสนุนการตรวจ span จากข้อความ การเชื่อมกฎทั้งสองและการคุ้มครองการคืนทางอ้อมเป็นข้อเสนอของโครงงาน ไม่ได้นำโค้ดหรือโมเดลของทั้งสอง paper มาใช้ ใช้การจัดกลุ่ม X-AMR และต้นฉบับเดิมตาม NOTICE.md; ImCoref-CeS ไม่เข้าเงื่อนไขเพราะ [v1 ปี 2025](https://arxiv.org/abs/2510.10241v1)

ใช้ gold เฉพาะวัดผล และไม่เปลี่ยน annotation วัด CoNLL F1, Pair P/R/F1, FP/FN, จำนวนเส้นตัด/veto/คืน, คู่ ARG1 ที่ยังเชื่อมอยู่ และความต่างของกลุ่มระหว่างลำดับ รันและตรวจ replay หนึ่งรอบแล้วหยุดลองกฎบน dev ชุดนี้ ไม่เปิด test_common เพิ่ม ไม่ใช้ API

### ลำดับและการเชื่อมทางอ้อม

- Ann1 พบหลักฐาน ARG1 ระดับประโยค 191 mentions ตัด 3 เส้น แต่ปลายเส้นยังอยู่ด้วยกันทั้ง 3 คู่ Temporal ระงับ 159 ครั้งทั้งก่อนและหลังตัดเส้น มีผู้สมัครคืน 2 เส้นและไม่ผ่านหลักฐานข้อความทั้งคู่
- Ann2 พบหลักฐาน 325 mentions ตัด 157 เส้น แต่ปลายเส้นยังเชื่อมถึงกัน 156 คู่หลัง Temporal จำนวน veto และผู้สมัครคืนยังอยู่ที่ 913 และ 371 ตามลำดับ ไม่ว่าจะตัด ARG1 ก่อนหรือไม่ คืน 11 คู่กลุ่มทั้งแบบคุ้มครองและแบบไม่คุ้มครอง และไม่มีเส้นคืนที่ต้องระงับด้วยกฎคุ้มครอง
- เทียบทั้งสามลำดับแบบรายคู่แล้วได้กลุ่มเหมือนกันใน dev สองชุดนี้ การทดสอบกรณีจำลองยืนยันว่ากฎคุ้มครองจะกันการรวมทางอ้อมได้ถ้ามีคู่ที่ปลายเส้น ARG1 ถูกแยกจริงและอีกเส้นพยายามรวมสองกลุ่ม ส่วนข้อมูลจริงรอบนี้ไม่มีกรณีดังกล่าว
- คู่ที่การประกอบแก้เพิ่มบน Ann2 คือ `23_2ecbplus.xml_21` / `23_5ecbplus.xml_20` ค่า ARG1 ฝั่งหนึ่งเป็นนักปีนเขาสองคน อีกฝั่งเป็น Duncan Rait และอยู่คนละกลุ่มอ้างอิง การตัดเส้นในกรณีนี้ช่วย แต่การมีข้อความอยู่ในประโยคยังไม่ยืนยันว่า argument เป็นบทบาทของเหตุการณ์เป้าหมายหรือหมายถึงคนละฝ่ายเสมอ

### ภาพรวมและขอบเขตข้อสรุป

1. [CohTP-inspired recovery](XAMR_COHTP_RECOVERY_TH.md) กู้ Ann2 จาก Temporal เดิม 76 คู่และเพิ่มคู่รวมผิด 4 คู่ โดยไม่มีการเปลี่ยนบน Ann1
2. [EAE-inspired source alignment](XAMR_SOURCE_ALIGNED_ARGUMENTS_TH.md) เมื่อใช้คู่กับ OR โดยตรง หลักฐานระดับประโยคลดคู่รวมผิด 4 คู่บน Ann2 และไม่เพิ่มคู่แยกผิด แต่หลักฐานจากทั้งเอกสารเพิ่มคู่แยกผิด 167 คู่
3. การประกอบบน Temporal ช่วยลดคู่รวมผิดเพิ่มหนึ่งคู่จากการคืนเส้นอย่างเดียวบน Ann2 คะแนนยังต่ำกว่า OR บน Ann2 ส่วน Ann1 คงผล Temporal เดิม จึงหยุดเพิ่มกฎบน dev ชุดเดิม ขั้นถัดไปต้องมีการตรวจอิสระว่าข้อความใดโยงกับบทบาทและวันของเหตุการณ์ รวมถึงชุดประเมินชุดใหม่ที่ไม่มีส่วนในขั้นเลือกกฎ ก่อนสรุปว่าผลใช้ได้กับข่าวอื่น

## ทำซ้ำ

```sh
.venv-xamr/bin/python xamr_lab/guarded_recovery.py --dataset ann1-dev
.venv-xamr/bin/python xamr_lab/guarded_recovery.py --dataset ann2-dev
(cd xamr_lab && ../.venv-xamr/bin/python -m unittest -q test_engine test_cloud test_date_evidence test_temporal_ablations test_cross_time_recovery test_source_aligned_arguments test_guarded_recovery)
```

ผลอยู่ใน `xamr_lab/runs/guarded-recovery/` รอบ Ann1 `20261115T145146-3a4828e9` และ Ann2 `20261115T145145-27befab7` มี config, hashes, metrics, predictions, คู่ที่เปลี่ยนและหลักฐานการคืนเส้น ใช้ dependency เดิมบน CPU ไม่มีการสุ่ม ตรวจ baseline ราย mention และรายการตัด ARG1 ตรงกับรอบเดิม ตรวจ replay ได้ CSV และ config ตรงกัน ผ่าน 28 tests เวลา inference รอบแรกประมาณ 0.68–0.69 วินาทีต่อชุดสำหรับ matrix และตัววินิจฉัยทั้งหมด โดยไม่รวมการโหลดข้อมูลและคำนวณคะแนน
