ทดลองเปรียบเทียบข้อมูลจากสองข่าว

กรอกข้อมูลจากต้นฉบับด้วยตัวเอง เพื่อดูว่าเหมือนกัน ต่างช่วงเวลา หรือควรตรวจสอบเพิ่ม

ต้นแบบนี้ใช้กฎเปรียบเทียบข้อมูลที่กรอกเอง ยังไม่ได้สกัดข่าวหรือใช้ NLI และไม่ได้ยืนยันว่าข่าวจริงหรือขัดแย้งกัน กรุณาตรวจต้นฉบับและความหมายของมูลค่า

ตั้งเกณฑ์เองก่อนเปรียบเทียบ: 0 = ต้องเท่ากันพอดี · ค่าเริ่มต้น 0.5% ของค่าที่มากกว่าเป็นเพียงตัวอย่าง ไม่ใช่มาตรฐาน · ใช้รหัสสกุลเงิน เช่น THB / USD โดยยังไม่แปลงสกุลเงิน
