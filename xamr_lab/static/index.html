01 เลือกข้อมูล

ดาวน์โหลดแบบฟอร์ม JSON ↗
ต้องมี gold_cluster สำหรับวัดผล · ยังไม่รองรับข่าวดิบหรือ Excel
รูปแบบข้อมูลและขอบเขตการประเมิน

หนึ่งแถวคือ event mention ที่ระบุตำแหน่งไว้แล้ว ไม่ใช่ข่าวทั้งบทความ ต้องมี mention_id, topic, doc_id, sentence_id, lemma, roleset_id, arg0, arg1, argL, argT และ gold_cluster ช่อง argument ว่างได้ แต่ไม่เติมคำตอบเอง

Ann1/Ann2 คือผู้ทำ annotation ของข้อมูลเดียวกัน ห้ามนำมานับเป็นข้อมูลอิสระสองชุด · GPT-4 คือผลที่ผู้เขียนเผยแพร่ ไม่ใช่การเรียกโมเดลใหม่

02 กำหนดการทดลอง

Annotation เดิม→EID เดิม→กราฟเดิม→ตรวจเวลาก่อนรวมกลุ่ม→Gold evaluation
0 = ช่วงเวลาต้องซ้อนกัน · เลือกค่าจาก train/dev เท่านั้น
ทดสอบ EID_N, EID_lt, AND, OR และ OR + temporal บนข้อมูลชุดเดียวกันทุกครั้ง ข้อมูลเวลาที่อ่านไม่ได้จะเป็น unknown ไม่ใช่ conflict
สมมติฐานและข้อจำกัดของวิธีที่เสนอ

ก่อนรวมสองกลุ่ม จะตรวจทุกคู่ข้ามกลุ่มที่มีช่วงเวลาระบุได้ หากพบช่วงที่แยกจากกันเกินค่าที่กำหนดจะไม่รวมกลุ่มนั้น ประมวลผลเส้นเชื่อมตาม mention_id อย่างคงที่ ผลอาจขึ้นกับลำดับนี้

วันที่ต้องเป็นเวลาเหตุการณ์ ไม่ใช่วันเผยแพร่ข่าว วิธีนี้อาจแยกเหตุการณ์ที่ดำเนินต่อเนื่องออกจากกัน ไม่รับประกันว่าคะแนนดีขึ้น ไม่ใช่ CohTP และไม่ได้เพิ่ม GNN

CPU · ไม่เรียก LLM · ไม่ใช้ VerbNet

ออนไลน์: ไม่เกิน 2,000 mentions · ประวัติเก็บในเบราว์เซอร์นี้ · ดาวน์โหลด ZIP ก่อนล้างข้อมูลเบราว์เซอร์
