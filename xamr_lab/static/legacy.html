เปิด Pair Workbench ในเครื่อง

ใช้เวอร์ชันเต็มสำหรับนำเข้า Excel/CSV แก้โค้ด Python รันการทดลอง และเปิดผลที่เก็บไว้ในเครื่อง

บน macOS เปิด pair_workbench/Start_Workbench.command หลังติดตั้ง dependencies หรือรันจากโฟลเดอร์ repository ด้วย Python 3.12

cd pair_workbench
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py

เมื่อเซิร์ฟเวอร์เริ่มทำงานแล้ว เปิด URL ที่แสดงใน Terminal

ซอร์สโค้ดเว็บเก่า คู่มือใช้งาน
